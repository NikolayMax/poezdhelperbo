# 🚂 Туда-Сюда — бот для поиска поездов

Бот для мессенджера **Max**, который помогает найти поезда и электрички по любому маршруту в России.

## Возможности

- **Поиск по станциям** — выбери город отправления и прибытия
- **Выбор даты** — удобный календарь с выбором месяца и дня
- **Результаты за 3 дня** — список поездов с ценой, временем, свободными местами
- **10 бесплатных запросов** — попробуй без ограничений
- **Пакеты запросов** — купить 10/50/200 запросов с 30-дневным сроком годности

## Команды

| Команда | Описание |
|---|---|
| `/start` | Начать работу |
| `/buy` | Купить пакет запросов |

## Переменные окружения (.env)

| Переменная | Описание |
|---|---|
| `MAX_BOT_TOKEN` | Токен бота Max |
| `ADMIN_USER_ID` | ID администратора для пополнения баланса |

## Запуск

```bash
# Установка
npm install

# Разработка
npm run start:dev

# Сборка
npm run build
```

**Требуется:** Redis (для сессий), Node.js 18+
